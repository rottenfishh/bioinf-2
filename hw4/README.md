## 2. Аннотация

- **ClinVar**: поиск по 50 rsID, экспорт Tabular (31.10.2026); сопоставление по координате и аллелям (Canonical SPDI).
- **gnomAD**: частоты для всех вариантов — из VEP; для трёх разобранных вариантов — проверка в браузере gnomAD v4.1.2 (значения совпали).

**Правило выбора транскрипта:** последствие на транскрипте MANE Select (есть у всех 50 вариантов). Если вариант задевает MANE Select нескольких генов, берётся самое тяжёлое последствие по ранжированию Ensembl. Дополнительно в таблице приведено худшее последствие по всем транскриптам.

## 5. Заключение

Интереснее всего варианты, где источники или транскрипты расходятся. rs115458101 показывает, что без явного правила выбора транскрипта легко получить ложную loss-of-function. rs116782322 — что тяжесть аминокислотной замены сама по себе не означает патогенность. rs75377686 — типичный вариант без клинической оценки, где вывод делается только по частоте. Наиболее «подозрительными» остаются редкие миссенс-варианты без записи в ClinVar (например, SEC14L3 p.I232S), но редкость не равна патогенности. В целом набор клинически спокойный, что ожидаемо для демонстрационного файла.

**Ограничения:**
- VCF без генотипов, качества и фильтров: неизвестна зиготность и надёжность вызова.
- VEP аннотирует формально по моделям транскриптов; результат зависит от набора транскриптов, версии и правила выбора. Предикторы патогенности (SIFT, PolyPhen, AlphaMissense) не использовались.
- ClinVar покрывает лишь 13 из 50 вариантов; классификации различаются по надёжности и могут устаревать (часть оценок 2018–2019 гг.).
- gnomAD — условно здоровые взрослые с перекосом к европейскому происхождению; частоты различаются по популяциям, и отсутствие варианта в базе не доказывает патогенность.
